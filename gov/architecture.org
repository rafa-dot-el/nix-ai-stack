#+title: Architecture — nix-ai-stack
#+date: <2026-10-31>
#+filetags: :architecture:governance:

A Nix flake that packages a personal AI stack: coding agents (Claude, Goose, Hermes, Antigravity), generic AI tools, first-party MCP servers, a local inference runtime, and one MCP proxy that every agent talks to. The thesis: agents, tools and MCP servers are configured once, declaratively, hardened against self-update and telemetry, and reached through a single filtered MCP entry point.

* System Overview
Consumers are NixOS and Home Manager configurations (first: the author's NixOS configuration repository). They import =nixosModules.default= / =homeManagerModules.default= and set options under =rafa.ai=. Packages are also usable directly from =packages.<system>.*= and =overlays.default= (=pkgs.rafa.ai.*=).

* Components
| Component | Kind | Responsibility |
|---|---|---|
| =packages/<name>= | third-party packaging | Build or repack an upstream tool with a hardened wrapper |
| =src/<project>= | first-party code | MCP servers and CLIs (Rust workspace + two Python projects) |
| =lib/= | pure Nix | hardening env, MCP config/unit rendering, voice config |
| =modules/home=, =modules/nixos= | modules | the =rafa.ai= option trees |
| Hermes (=default.nix=, =browser.nix=, =voice.nix=, =desktop.nix=, =nixos/=) | package + module | the flagship agent, unchanged layout |

* Communication
agent → stdio → =mcp client= → unix socket → =mcp proxy= → unix socket (socket-activated) → MCP server service. Details in [[file:adr/ADR-0004-mcp-proxy-architecture.org][ADR-0004]].

* Technology Stack
Nix flakes (nixos-26.05 + nixos-unstable), Taskfile, Rust (rmcp, tokio, ratatui) for first-party MCP code, Python (uv2nix) for calibrectl/zoteroctl, systemd user units for services.
